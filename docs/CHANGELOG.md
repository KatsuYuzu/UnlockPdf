# Changelog

## 2.0.0

### Added

- Windows x64向け自己完結型・単一ファイルの配布を追加
- `v*`タグpush時のGitHub Release自動作成を追加

### Changed

- .NET Framework 4.5から.NET 8 LTSへ移行
- iTextSharpからQPDFベースのPDF解除処理へ移行
- LivetとReactivePropertyをCommunityToolkit.Mvvmへ移行
- MahApps.MetroとMaterial Designを.NET 8対応の現行安定版へ更新
- 元ページのサイズ、回転、内容を保持する処理へ変更
- リポジトリ構成を`src`と`docs`中心に整理

### Fixed

- 編集権限制限付きPDFでページ取り込みが失敗する問題
- 通常とは異なるページサイズで出力内容が欠ける問題

## 1.1.0 - 2016-07-28

- UNLOCKショートカットを追加
- 完了後にExplorerを開く機能を追加
- ファイルパス判定を修正

## 1.0.0 - 2016-07-28

- 初版
